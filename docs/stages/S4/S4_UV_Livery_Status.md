## 核心任务

- 车身主体、车门、检修舱、前脸、尾部和车顶 UV 分区；
- 左右车身使用独立 UV 与独立文字方向；
- 深灰腰线、青色主线和浅青辅助线连续跨越前侧后包角；
- 使用 mask 保留门缝、检修舱缝、窗洞、轮拱、灯具和密封胶条；
- 输出 BaseColor、Normal、ORM 和必要遮罩；
- 检查 UV 重叠、拉伸、镜像文字、条纹穿窗和包角断裂；
- 输出十二视角皮肤审查图与 UV 检查结果。

## S4 门禁

- 无非预期 UV 重叠；
- 主要可见面无明显纹理拉伸；
- 左右文字方向正确；
- 条纹不进入玻璃、轮拱、灯具和密封区；
- 门缝与检修舱缝可见；
- 前、侧、尾皮肤连续；
- 十二视角无明显断裂和漂浮；
- S4 最终审查通过后才允许进入 S5。
